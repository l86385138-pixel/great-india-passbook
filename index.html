Add / Edit Passbook Format

Admin पहले bank बनाये, फिर branch बनाये, फिर उस bank का passbook format upload करें। Format file HTML / HTM / TXT हो सकती है। Template में नीचे दिये placeholders लगाने पर customer data अपने आप भर जाएगा।
Existing saved template edit करते समय file दोबारा चुनना जरूरी नहीं है।
Template placeholders:
{{BANK_NAME}} {{BRANCH_NAME}} {{BRANCH_CODE}} {{IFSC}} {{MICR}} {{BRANCH_ADDRESS}} {{BRANCH_PHONE}}
{{MODE}} {{CUSTOMER_ID}} {{AADHAAR}} {{ACCOUNT_NO}} {{NAME}} {{ACCOUNT_OPEN_DATE}}
{{FATHER_RELATION}} {{FATHER_NAME}} {{ADDRESS}} {{NOMINATION}} {{ISSUE_DATE}} {{TOLL_FREE}} {{NODAL_OFFICER}}

📄 Upload Customer PDF
PDF upload करें। सिस्टम PDF से Customer ID, Aadhaar, Account No., Customer Name (MR/MS/KUMARI), Account Open Date, Father Name (S/O/D/O/W/O), Address, Nomination, Mode और Issue Date निकालकर नीचे form में भर देगा।
Note: Text-based PDF सबसे अच्छे तरीके से काम करेगा। Scanned/image-only PDF में OCR की जरूरत हो सकती है।
